# WinterWetter – öffentliches Wetterarchiv

Zwei tägliche Abrufe für Remscheid und Wermelskirchen, PDF-Monatsberichte und eine statische Website über GitHub Pages.

Abruf: 05:17 und 17:17 UTC; im Winter 06:17/18:17, im Sommer 07:17/19:17 deutscher Zeit. GitHub kann Ausführungen verzögern und Zeitpläne nach 60 Tagen ohne Repository-Aktivität deaktivieren.

Alle Dateien, Wetterdaten und Berichte dieses Repositories sind öffentlich. Es werden keine Kunden- oder Zugangsdaten gespeichert. Der Branch `weather-data` enthält den vollständigen SQLite-Archivstand und bis zu 14 Backups. Keine unabhängige externe Sicherung.

Wettermodellwerte sind keine Vor-Ort-Messungen. Koordinaten sind vorläufig. Zwei Abrufe pro Tag können kurzlebige Warnungen verpassen. Die kostenlose Open-Meteo-API ist für nichtkommerzielle Nutzung vorgesehen; eine gewerbliche Winterdienst-Dokumentation erfordert vorab Klärung der Anbieterbedingungen. Keine rechtsverbindlichen Einsatznachweise.
